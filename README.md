# scansvg

Scan HTML/Markdown svg fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/scansvg/

## Install / run

```bash
git clone https://github.com/theworker02/scansvg.git
cd scansvg
node src/cli.js
node --test
```
